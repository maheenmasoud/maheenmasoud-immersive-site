# maheenmasoud-immersive-site

An immersive redesign of my personal website ([maheenmasoud.github.io](https://github.com/maheenmasoud/maheenmasoud.github.io)), live at https://maheenmasoud.github.io/maheenmasoud-immersive-site/.

Features a canvas starfield with mouse parallax, drifting nebula blobs, a custom cursor, scroll-reveal animations, a tilting avatar, an animated typing subtitle, and a glassmorphism UI — built with plain HTML/CSS/JS, no build step required.

Content covers experience, education & honors, and research interests. No resume file is hosted here — contact links (LinkedIn/email) are provided instead.

## Run locally

Just open `index.html` in a browser, or serve the folder:

```
npx serve .
```
